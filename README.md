# Obys Agency — Frontend Reconstruction Study

An independent recreation study of the Obys Agency website, focused on interaction design, motion, typography, smooth scrolling, and the mechanics behind highly art-directed marketing sites.

> This is a learning/reconstruction project and is not affiliated with or endorsed by Obys Agency.

## What I explored

- GSAP timelines and scroll-linked animation
- Locomotive Scroll / smooth-scrolling patterns
- Shery.js visual effects
- Responsive layout and typography
- Mouse interactions and micro-transitions
- Rebuilding a reference experience from the ground up

## Stack

HTML · CSS · JavaScript · GSAP · Locomotive Scroll · Shery.js

## Run locally

Open the project with a local static server, then visit the served page in a browser.

## Why this exists

The interesting part is not copying a screenshot. It is understanding how motion, spacing, type, and interaction combine to make a page feel intentional.
